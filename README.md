# Food Waste Quantity Prediction Using Machine Learning

## Overview

This project predicts the expected quantity of food waste in kilograms for a restaurant using operational, historical, and environmental information.

The final machine learning model is **Linear Regression**.

The dataset is **synthetic and generated specifically for this portfolio project**. It is not presented as real restaurant data.

## Problem Statement

Restaurants need to estimate food waste so they can improve meal preparation and reduce unnecessary waste.

The model predicts:

**`food_waste_kg` — expected food waste in kilograms**

## Features

- Day of week
- Weekend indicator
- Holiday indicator
- Special-event indicator
- Temperature
- Rainfall
- Customer count
- Meals prepared
- Meals sold
- Previous food waste
- Average meal price
- Staff count
- Occupancy rate
- Food category

### Engineered features

- `unsold_meals = meals_prepared - meals_sold`
- `temperature_above_25 = max(temperature_c - 25, 0)`

## Machine Learning Workflow

1. Generate/load data
2. Validate and remove duplicate rows
3. Exploratory data analysis
4. Feature engineering
5. Train/test split
6. Numerical preprocessing with median imputation and standardization
7. Categorical preprocessing with one-hot encoding
8. Train Linear Regression
9. Evaluate using MAE, RMSE, and R²
10. Save the complete preprocessing + model pipeline
11. Make predictions
12. Deploy with Streamlit

## Data Leakage Prevention

The target column `food_waste_kg` is never used as an input feature.

The model pipeline is fitted only on the training data. Test data is passed through the already-fitted preprocessing steps.

The date column is not directly used as a predictor.

## Results

The model is evaluated on a held-out 20% test set. The exact metrics are generated by `train.py` and saved to:

`reports/model_results.csv`

Do not describe the synthetic dataset as real-world restaurant data.
